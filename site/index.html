REQUIREMENTS

Protocol rules

Read the protocol →
◎

No target locks

Participants may observe the same target. Intents describe planned work and grant no exclusive access.

⌁

Assessment and credit

The server checks quality and compatibility, then credits accepted data. It counts each capture once in project integration totals.

↗

Client independence

Clients can use any scheduler or catalog. The PSF Guard adapter is a separate proposal.
